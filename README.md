# Age Calculator

A simple and responsive **Age Calculator** built with **React** and **TypeScript**.  
This project helps users calculate their exact age in years, months, days, and more with a clean and easy-to-use interface.

## 🚀 Live Demo

[Visit the app](https://iagecalculator.netlify.app/)

## ✨ Features

- Calculate exact age from date of birth
- Shows age in years, months, and days
- Clean and responsive UI
- Fast and lightweight
- Built with modern React + TypeScript

## 🛠️ Tech Stack

- React
- TypeScript
- HTML
- CSS
- Netlify for deployment

## 📦 Installation

```bash
git clone https://github.com/ArpanCodeX/Age-CalC.git
cd age-calculator
